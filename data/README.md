# 📁 Data Directory

This directory contains all the content data for the Starbucks app.

## 📄 Files

### Content Data Files
- **`posts.ts`** - All posts/drops content (images, videos, descriptions)
- **`storiesData.ts`** - Stories content and configuration

### Documentation Files
- **`POSTS_README.md`** - Complete guide for managing posts
- **`POSTS_QUICK_GUIDE.md`** - Quick reference for adding posts
- **`POSTS_STRUCTURE.md`** - Technical architecture diagram

## ⚡ Quick Start

### To add a new post:
1. Open `posts.ts`
2. Add a new object to the `posts` array
3. Save

### To edit existing post:
1. Open `posts.ts`
2. Find the post by ID
3. Update the image/video URL or description
4. Save
